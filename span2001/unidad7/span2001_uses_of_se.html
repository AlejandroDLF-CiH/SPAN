The many uses of SE

One small word, several different functions.

When you see se, do not translate it immediately.
Starting point

Does SE mean the same thing here?

Juan se levanta a las ocho.
Ana y Juan se abrazan.
Se lo doy.
Se venden pisos.
No. The form is the same, but the function changes.
The map

Five core uses + one common case

TypeExampleSimple idea
1. ReflexiveJuan se lava.himself / herself
2. ReciprocalAna y Juan se abrazan.each other
3. LE / LES → SESe lo doy.replacement before lo/la/los/las
4. PassiveSe venden pisos.something is done
5. ImpersonalAquí se vive bien.people / one in general
+ Pronominal verbJuan se va.SE is part of the verb
1 · Reflexive SE

The action returns to the subject

JUAN   →   JUAN
Juan se lava.

The subject performs the action on himself / herself.

lavarse

Juan se lava.

mirarse

María se mira en el espejo.

vestirse

Pedro se viste.

Reflexive pronouns

Remember: it is not always se

me levanto
te levantas
se levanta
nos levantamos
os levantáis
se levantan

SE is the third-person reflexive form.

2 · Reciprocal SE

The action goes both ways

ANA   ↔   JUAN
Ana y Juan se abrazan.

Two or more people perform the same action on each other.

se saludan
se miran
se ayudan
se escriben
Reflexive or reciprocal?

Same form, different relationship

REFLEXIVE
Juan → Juan

Juan se lava.

himself

VS.
RECIPROCAL
Ana ↔ Juan

Ana y Juan se miran.

each other

Useful test: Can we add el uno al otro?
3 · LE / LES → SE

A familiar SE from CD + CI

Doy el libro a María.
a María → le
el libro → lo
❌ Le lo doy.    →    ✅ Se lo doy.

Here, se does not mean “himself” or “each other”.

LE / LES → SE

The rule

le / les + lo / la / los / las → se + lo / la / los / las

le + lo → se lo

le + la → se la

les + los → se los

les + las → se las

4 · Passive SE

Focus on what receives the action

ACTIVE IDEA
Construyeron este edificio en 1990.

Someone built this building.

→
PASSIVE SE
Este edificio se construyó en 1990.

This building was built in 1990.

Passive SE

The verb agrees with the subject

Se vende un piso.

one apartment → singular verb

Se venden pisos.

apartments → plural verb

Se alquila una habitación.
Se alquilan bicicletas.
5 · Impersonal SE

People in general — without saying who

En España se cena tarde.
≈ People eat dinner late in Spain.

Aquí se vive bien.

En España se come tarde.

Se habla mucho de este problema.

The verb is in the third-person singular.

Passive vs. impersonal

These two uses look similar — but they are not the same

PASSIVE
Se venden casas.

casas is the subject.

The verb agrees with it:

Se vende una casa.
Se venden tres casas.

IMPERSONAL
Aquí se vive bien.

No specific person is the subject.

Meaning: people in general.

SE + 3rd-person singular

+ Pronominal verbs

Sometimes SE is simply part of the verb

Juan se va a casa.

irse = to leave / go away

María se queda en casa.

quedarse = to stay

Pedro se arrepiente.

arrepentirse = to regret

Ana se queja mucho.

quejarse = to complain

Pronominal verbs

Do not force a translation for SE

irse · quedarse · quejarse · arrepentirse

Learn the verb together with SE.

ir

to go

≠
irse

to leave / go away

One form, different functions

Practice 3 · Passive or impersonal?

Look for agreement

1. Se alquilan apartamentos.

Passive — apartamentos is the subject; the verb is plural.

2. Aquí se trabaja mucho.

Impersonal — people in general; 3rd-person singular.

3. Se venden dos entradas.

Passive — dos entradas is the subject; the verb agrees.

4. En esta ciudad se vive muy bien.

Impersonal — people in general.
Final strategy

When you see SE...

1

Do not translate it immediately.

2

Look at the verb and the other elements in the sentence.

3

Ask: What function is SE performing here?

Meaning comes from the structure, not from SE alone.
