Talking about the weather

Spanish uses several different structures to describe weather and natural phenomena.

Page 2

Four ways to talk about the weather

1. ESTAR + adjective
Está nublado.
2. Weather verbs
Llueve. / Nieva.
3. HAY + noun
Hay nubes. / Hay niebla.
4. HACE + weather expression
Hace frío. / Hace calor. / Hace sol. / Hace viento.
Spanish does not use just one structure for all weather expressions.
Page 3

1. ESTAR + adjective

ESTAR + adjective

We can use estar + adjective to describe the current state of the weather.

Está nublado.
It is cloudy.
Está despejado.
It is clear.
Está soleado.
It is sunny.
This structure should already look familiar: ESTAR + adjective.
Page 4

2. Weather verbs

Some natural phenomena are expressed directly with a verb.

llover = to rain

Llueve.
It rains. / It is raining.
nevar = to snow

Nieva.
It snows. / It is snowing.
When used for the weather, these verbs are normally in the third person singular.
En otoño llueve mucho.
En invierno nieva.
Page 5

3. HAY + noun

HAY + noun

We use hay to say that something is present.

Hay nubes.
There are clouds.
Hay muchas nubes.
There are many clouds.
Hay niebla.
There is fog.
Hay una tormenta.
There is a storm.
HAY does not change:
Hay una nube. / Hay muchas nubes.
Page 6

4. HACE + weather expression

This is the main new structure in this lesson.

HACE + weather expression
Hace frío.
It is cold.
Hace calor.
It is hot.
Hace sol.
It is sunny.
Hace viento.
It is windy.
In weather expressions, hace describes a general weather condition.
Page 7

HACE does not change

Hace comes from the verb hacer, but in weather expressions we use the third person singular.

En Madrid hace calor.
En Barcelona hace calor.
En Madrid y Barcelona hace calor.
Always use hace in these weather expressions.
Not: ❌ hacen calor

Compare with normal hacer

Yo hago ejercicio.
Tú haces ejercicio.
Ella hace ejercicio.
Hace frío.
Hace calor.
Hace viento.

Page 9

HACE vs HAY

HACE HAY
describes a general weather condition says what is present
Hace frío. Hay nubes.
Hace calor. Hay niebla.
Hace sol. Hay una tormenta.
Hace viento. Hay muchas nubes.
HACE = weather condition
HAY = something is present
Page 10

English vs Spanish

English often uses “it is”, but Spanish uses different structures.

It is cloudy. → Está nublado.
It is raining. → Llueve.
There are many clouds. → Hay muchas nubes.
It is cold. → Hace frío.
It is windy. → Hace viento.
Do not translate English “it is” word by word.

Summary

Structure Use Example
ESTAR + adjective state / condition Está nublado.
weather verb natural phenomenon Llueve. / Nieva.
HAY + noun something is present Hay nubes.
HACE + expression general weather condition Hace frío.
HACE + frío / calor / sol / viento
HACE is always third-person singular in these weather expressions.
