MUY and MUCHO

How to say “very”, “much” and “many” in Spanish

MUY and MUCHO can correspond to English very, much or many.
Page 2

MUY = very

MUY + adjective / adverb
MUY does NOT change.
muy interesante
very interesting
muy bonito
very beautiful
muy grande
very big
muy turístico
very touristy
Habla muy rápido.
He / She speaks very fast.

Remember

✓ muy bonita

✓ muy interesantes

✗ muya bonita

✗ muys interesantes

Page 3

MUCHO / MUCHA / MUCHOS / MUCHAS

= much / many

MUCHO / MUCHA / MUCHOS / MUCHAS + noun

They change according to the gender and number of the noun.

Singular Plural
Masculine mucho muchos
Feminine mucha muchas
mucho frío
a lot of cold / very cold
mucha carne
a lot of meat
muchos restaurantes
many restaurants
muchas montañas
many mountains
The form agrees with the noun.
Page 4

VERB + MUCHO

verb + MUCHO
When MUCHO modifies a verb, it does NOT change.
Trabajo mucho.
I work a lot.
Estudio mucho.
I study a lot.
Viajo mucho.
I travel a lot.
Llueve mucho.
It rains a lot.

Same form

Yo estudio mucho.
Ana estudia mucho.
Mis amigos estudian mucho.
