01 / The big picture · 先看整體

Groups of three, from right to left.

Keep the same board. Change the digits, one step at a time.
數位框架保持不變，從右邊開始，每三位一組。

Common everyday notation

Spain: 1.234,56
UK / US: 1,234.56

西班牙日常常見逗號作小數分隔符、點號作三位分組。不同西語國家的習慣不完全相同。

This lesson uses whole numbers only. · 本課只練習整數。

The dots mark groups.

1.000 → mil
1.000.000 → un millón
1.000.000.000 → mil millones

最左側的「十億」組只作延伸認識。今天的核心是 100 至 100 萬。

Formal writing: use spaces to group digits, e.g. 1 234 567,89.
現行正式書寫規範以空格分組；本課保留點號，作為數位教學框架。小數分隔符可因地區而用逗號或點號。
Read the value of each group. Do not read every dot as a word.
點號不是要逐個念出的詞。跳過全為零的組，也不讀前面的補位零。

02 / Review · 複習 0–99

Start with what you know.

Remember the accents.

dieciséis · veintidós
veintitrés · veintiséis

From 31: tens + y + units.

treinta y uno
cuarenta y cinco

整十後沒有個位數時，不加 y：treinta、cuarenta。

03 / One hundred · 一百

Cien or ciento?

Exactly 100 → cien

cien libros
cien camisetas

正好一百用 cien，不隨名詞的陰陽性改變。

101–199 → ciento + …

101 → ciento uno
111 → ciento once
125 → ciento veinticinco

在同一個百位組中，100 後還有十位或個位的數值，用 ciento。

No y after cien / ciento.

101 → ciento uno   ciento y uno
131 → ciento treinta y uno

Still cien before mil and millones: cien mil · cien millones.
不能簡單記成「所有大於 100 的數都用 ciento」。
04 / Hundreds · 二百至九百

Doscientos libros. Doscientas camisetas.

The hundreds from 200 to 900 change for gender.
200–900 隨所修飾的名詞改變陰陽性；這不是另外一套單複數變化。

NumberMasculine · 陽性Feminine · 陰性
Learn these three carefully: quinientos · setecientos · novecientos

Load a number, choose a noun, say it, then reveal. · 選數字和名詞，先說，再顯示。

05 / Thousands · 千與十萬

Mil. Dos mil. Cien mil.

1.000 = mil

mil libros
mil camisetas

un mil   dos miles libros

表示確切數量時，mil 不改變陰陽性，也不加複數 -es。

Read the thousands, then the rest.

2.350 → dos mil trescientos cincuenta
10.000 → diez mil
100.000 → cien mil

中文「一萬」在西班牙語中是「十個千」：diez mil。

Mil stays the same, but the hundreds still agree.

doscientos mil libros
doscientas mil camisetas

Later: miles de… · 延伸

Miles de personas means “thousands of people”, an approximate quantity.
miles de… 是另一個名詞結構，表示「數以千計的……」。

06 / One million · 一百萬

Un millón → dos millones

Use un; change millón to millones.

1.000.000 → un millón
2.000.000 → dos millones

millón 是陽性名詞，有單複數。millón 有重音符號，millones 沒有。

Exact millions + de + noun

un millón de libros
dos millones de camisetas

millón 本身仍是陽性：un millón de camisetas。

When more numbers follow, omit de:

un millón doscientas mil camisetas

對比：1.000.000 件 → un millón de camisetas；1.200.000 件 → un millón doscientas mil camisetas。

The leftmost group · 最左一組的延伸

1.000.000.000 → mil millones

English: one billion. Spanish un billón is 1.000.000.000.000.

這部分只作數位延伸認識，超出今天的核心範圍。

07 / Put it together · 組合起來

Read the groups. Link them carefully.

Y joins tens and units.

321.456
trescientos veintiún mil
cuatrocientos cincuenta y seis

不在百與十之間加 y，也不在千與後面的數字之間加 y。

Uno changes before a noun.

101 → ciento uno
101 libros → ciento un libros
101 camisetas → ciento una camisetas

21 同樣變化：veintiuno → veintiún libros / veintiuna camisetas。

Before mil: veintiún mil; before millones: veintiún millones.
修飾陰性名詞時，也可以說 veintiuna mil camisetas。本頁的讀法器採用這個陰性形式。
